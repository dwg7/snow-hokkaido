# 2. 使っている技術

データが「衛星」から「あなたの画面」に届くまでの、道のりに沿って説明します。

```
衛星の写真 → 雪を見つける計算 → 区画(セル)にまとめる → 市町村ごとに数える → 台帳に保存 → 画面に表示
```

## 衛星の写真を手に入れる

### Sentinel-2 (センチネル・ツー)
ヨーロッパの地球観測衛星です。写真のデータは**だれでも無料**で使えます。1つの写真(1シーン)に、色の成分ごとの画像(バンド)が入っています。このプロジェクトで使うのは3つです。

| バンド | 中身 | 使い道 |
|---|---|---|
| B03 | 緑色の光 | 雪は緑の光をよく反射します |
| B11 | 短波長赤外線 (人の目には見えない光) | 雪はこの光をあまり反射しません |
| SCL | 画素ごとの分類ラベル | 雲・雲の影・雪などの目印 |

### STAC (スタック)
「どの場所の、いつの写真が、どこにあるか」を調べるための共通の決まりです。図書館の検索システムのようなものです。このプロジェクトでは [Earth Search](https://earth-search.aws.element84.com/v1) という検索窓口を使い、「大雪山あたりの、10月18日の写真」を探します。

### COG (Cloud Optimized GeoTIFF)
とても大きな画像ファイルを、**必要な一部分だけ**取り出せるように作った形式です。写真1枚は約1億画素もありますが、COG なら、見たい場所の四角だけをインターネット越しに読めます。全部ダウンロードしなくてよいので、速くて、ディスクもいりません。

## 雪を見つける計算

### NDSI (正規化差分積雪指数)
雪は「緑の光をよく反射し、短波長赤外線をあまり反射しない」性質があります。この差を計算します。

```
NDSI = (B03 − B11) ÷ (B03 + B11)
```

値が大きいほど雪っぽい、という指数です。このプロジェクトでは **0.42 以上を雪**とみなしています(ヨーロッパ宇宙機関の処理ソフトが使う値を借りた、暫定の設定です)。

## 区画 (セル) にまとめる

### XYZタイルとセル
地図を、ズームごとに正方形に切り分ける決まりが「XYZタイル」です。ズームを1つ上げるごとに、1枚が4枚に分かれます。このプロジェクトでは、**ズーム18のタイル1枚を「セル」**と呼び、これを場所の最小単位にしています。北海道では1辺がおよそ112メートルです。

衛星写真の1画素は10メートルなので、1セルには約11×11=121画素が入ります。セルごとに、画素の多数決で「緑・雪・雲・影」を決めます。

セルは「ズーム18 のどのタイルか」という番号(x, y)で一意に決まるので、住所のように扱えます。

### 市町村との結びつき
各セルの**中心の点**が、どの市町村の中にあるかを調べて、1回だけ割りふります(点の内外判定)。境界のセルは最大で半セル分ずれることがありますが、割りきって単純にしています。こうしておくと、市町村ごとの集計は「市町村ごとに数える」だけで済みます。市町村の境界は、国土数値情報(国土交通省)の「行政区域」を使いました。

## 保存する

### Parquet (パーケット)
表のデータ(行と列)を、小さく速く読める形で保存するファイル形式です。市町村ごと・観測ごとの数(雪が何セル、雲が何セル…)をこの形式で書いています。Excel と同じ「表」ですが、ずっと大きなデータを扱えます。

(予定: DuckDB という道具で、Parquet をブラウザやコマンドから直接集計します。まだ使っていません。)

## 見せる

### MapLibre GL JS
ブラウザの中で、地図を描くための無料のプログラム部品です。ズームしたり、動かしたりできる地図は、これで描いています。

### bvmap-starlight (背景地図)
国土地理院が公開している「ベクトルタイル」を使った、背景地図のデザイン(スタイル)です。道路や地名を、落ち着いた色で出します。雪の色(青)を目立たせるため、背景は控えめな色を選びました。

### tabularmaps (表の地図)
市町村の面積はバラバラです(札幌は広く、小さな町はとても小さい)。そのため、普通の地図では小さな町が見えません。tabularmaps は、**北海道の179市町村を、同じ大きさの四角で並べた図**です。形はすこしゆがみますが、全部の町が同じ大きさで見えるので、「どこで雪が増えたか」を一目で比べられます。このプロジェクトでは、先に作られた [tabularmaps/do](https://github.com/tabularmaps/do) の部品を、ライセンス(CC0=自由に使ってよい)を確認したうえで取り込みました。

### Open MCT (オープン・エムシーティー)
NASA が、宇宙船の状態を監視するために作った**計器盤のソフト**です。左に「計器の一覧」があり、選ぶと右に計器が表示されます。このプロジェクトでは、その中に「地図(MapLibre)」と「表の地図(tabularmaps)」の2種類の計器を並べています。

### GitHub Pages
GitHub が提供する、ウェブページを公開する仕組みです。`docs/` フォルダの中身がそのままウェブサイトになります。サーバーを自分で用意する必要がありません。

## 開発の道具

| 道具 | 役割 |
|---|---|
| Python | データを処理するプログラム言語 |
| uv | Python の部品(ライブラリ)をまとめて用意する道具 |
| just | よく使うコマンドに名前をつける道具 (`just test` など) |
| GDAL / rasterio | 衛星画像や地図データを読み書きする道具 |
| pytest | 自動テスト。数え方に矛盾がないか検算する |
| git / GitHub | 変更の履歴を残し、公開する |

## 「サーバーなし」という方針

このプロジェクトは、いつも動いているコンピューターを持ちません。必要なのは、**ファイルを置いておく場所**だけです。大きなデータは COG と Parquet のファイル、軽い結果だけを GitHub Pages に置きます。壊れにくく、お金もかからず、だれでも真似できます。
